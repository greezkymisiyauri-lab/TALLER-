Control de Versiones

GIT

Git: El Estándar de la Industria

Git es un sistema de control de versiones distribuido, lo que significa que cada desarrollador tiene una copia completa del historial del proyecto en su máquina local.

Eficiencia en Ramas

Crea, fusiona y elimina ramas en segundos para experimentar sin riesgo.

Integridad de Datos

Cada cambio es rastreado con un hash criptográfico único (SHA-1).

Comandos Esenciales:

git init - Inicializa un repo.
git add . - Prepara cambios.
git commit -m "msj" - Guarda cambios.
git branch - Gestiona ramas.
GH

GitHub: Colaboración Global

GitHub es la plataforma de alojamiento en la nube líder que potencia la colaboración mediante herramientas de gestión de proyectos y automatización.

  • Pull Requests: Facilita la revisión de código por pares.
  • GitHub Actions: Automatiza CI/CD directamente en el repo.
  • Issues: Rastreo eficiente de errores y nuevas funciones.
  • GitHub Pages: Despliegue estático gratuito para proyectos.

Flujo Remoto:

git remote add origin URL
git push -u origin main
git pull origin main
